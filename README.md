# 📖 Diário em Python

O objetivo deste projeto foi praticar a manipulação de **arquivos JSON**, criando um diário digital capaz de armazenar páginas de forma permanente, permitindo criar, visualizar, editar e excluir anotações.

---

#  Funcionalidades

-  Criar novas páginas do diário.
-  Visualizar todas as páginas salvas.
-  Ler uma página específica.
-  Editar páginas existentes.
-  Excluir páginas.
-  Salvamento automático em arquivo JSON.
-  Registro da data e hora de criação/edição.
-  Tratamento de erros para entradas inválidas.

---

#  Tecnologias utilizadas

- Python
- JSON
- Manipulação de arquivos
- Funções
- Listas
- Dicionários
- Estruturas de repetição
- Tratamento de exceções (`try/except`)

#  Como executar

1. Clone este repositório:

```bash
git clone https://github.com//Diario_Digital-CRUD_em_Python.git
```

2. Entre na pasta do projeto:

```bash
cd Diario_Digital-CRUD_em_Python
```

3. Execute o programa:

```bash
python diario.py
```

> **Observação:** É necessário ter o Python 3 instalado na máquina. O projeto utiliza apenas bibliotecas nativas (`json`, `time` e `sys`), portanto não é necessário instalar dependências adicionais.

#  Exemplo do arquivo JSON

```json
[
    {
        "nome": "Meu primeiro dia",
        "texto": "Hoje comecei meus estudos com JSON.",
        "data": "29/07/2026 21:30:10",
        "pagina": 1
    }
]
```
